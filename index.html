Youtube Live Chat

YouTube Live Chat Display Tool

概要 / About

Youtube Live Chatは、YouTubeライブ配信中の コメントを取得し、OBS Studioに表示するための 個人利用向けツールです。

Youtube Live Chat is a personal tool for displaying YouTube livestream chat messages in OBS Studio.

主な機能 / Features

  • 自分のYouTubeライブ配信を自動検出
  • YouTube Data APIによるコメント取得
  • 投稿者名・コメント・アイコン情報の取得
  • OBS Studioへのリアルタイム送信

Google APIの利用

本ツールはGoogle OAuth 2.0を使用して、 利用者本人のYouTubeアカウントへの アクセス許可を取得します。

取得したコメント情報は、ローカル環境で OBS Studioへ送信するために使用します。

プライバシー / Privacy

データの取り扱いについては、 プライバシーポリシー をご確認ください。
