Privacy Policy

Youtube Live Chat

最終更新日：2026年11月22日

1. アプリケーションについて

Youtube Live Chatは、利用者本人のYouTubeライブ配信から コメントを取得し、OBS Studioに表示するための 個人利用向けアプリケーションです。

2. 取得する情報

本アプリケーションは、以下の情報を取得します。

  • 認証されたアカウントのライブ配信情報
  • ライブチャットの投稿者名
  • ライブチャットのコメント本文
  • 投稿者のプロフィール画像URL
  • Google OAuth認証トークン

3. 情報の利用目的

取得した情報は、ライブ配信の検出および OBS Studioへのコメント表示のために使用します。

4. データの保存と共有

コメント情報はローカル環境のWebSocketを通じて OBS Studioへ送信されます。 サーバープログラムはコメント履歴をファイルに保存しません。

OAuth認証トークンは利用者のローカル環境に保存されます。 本アプリケーションは取得情報を広告目的で使用したり、 外部の分析サービスに送信したりしません。

OBS Studioで配信画面に表示されたコメントは、 YouTube配信の視聴者に公開される場合があります。

5. アクセス権の取り消し

利用者はGoogleアカウントの設定から、 本アプリケーションへのアクセス権を取り消せます。

Googleアカウントの接続管理

6. YouTube API Services

本アプリケーションはYouTube API Servicesを使用します。 利用にあたっては、以下の規約が適用されます。

  • YouTube利用規約
  • Googleプライバシーポリシー

7. お問い合わせ

本アプリケーションのデータ取り扱いに関する お問い合わせは、開発者までご連絡ください。
